{# Glossary term macro. Renders `label` with a dotted underline + ⓘ and a hover/tap tooltip (short + long) that links to the full /glossary entry. If the slug isn't in the glossary, renders `label` as plain text so cards never break. `GLOSSARY` is a Jinja global (registered in main.py); import this file `with context` so the macro can see it. #} {% macro g(key, label) -%} {%- set t = GLOSSARY.get(key) if GLOSSARY else none -%} {%- if t -%} {{ label }}ⓘ{{ t.title }}{{ t.short }}{% if t.long %}{{ t.long }}{% endif %}Full entry → {%- else -%}{{ label }}{%- endif -%} {%- endmacro %}
